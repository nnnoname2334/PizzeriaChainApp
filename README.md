## Описание
WPF-приложение с базой данных Microsoft SQL Server из трёх таблиц:
`pizzeria` (пиццерии), `customer` (клиенты и учётные записи), `customer_order` (заказы).
Связи: `customer_order → customer` и `customer_order → pizzeria`, удаление каскадное.

## Возможности
- Авторизация и регистрация с ролями «Пользователь» и «Администратор».
- Хэширование паролей (SHA-256 с солью), капча после 3 неверных попыток входа.
- Смена пароля.
- Страница пользователя: просмотр своих заказов, поиск, сортировка, фильтрация.
- Страница администратора: все заказы, пиццерии и клиенты; поиск, сортировка,
  фильтры, добавление, редактирование, каскадное удаление с подтверждением.
- Диаграмма сумм заказов клиента по пиццериям (8 типов диаграмм).
- Экспорт отчётов в Word (.docx), PDF и Excel (.xlsx).
- Светлая и тёмная темы, выбор сохраняется между запусками.
- Динамические заголовки страниц, плейсхолдеры, всплывающие подсказки,
  проверки и маски ввода, подтверждение выхода.

## Технологии
C#, WPF (.NET Framework 4.7.2), Entity Framework 6 (Database First, ADO.NET Entity Data Model),
Microsoft SQL Server, Office Interop (Word, Excel),
System.Windows.Forms.DataVisualization, шрифт Open Sans.

## Запуск
1. Установите Microsoft SQL Server и SSMS.
2. Выполните скрипт `db/schema.sql` (создаётся база `DB_Tretyak_PizzeriaChain`
   с тестовыми данными).
3. Откройте решение в Visual Studio, при необходимости измените `Data Source`
   в строке подключения в `App.config` (по умолчанию `localhost`).
4. Запустите проект (F5). Для экспорта нужны установленные Microsoft Word и Excel.
